8sync: public snapshot retired

The public repository 8-Sync-Dev/su-code is archived and no longer supported. 8sync is now an omp-only harness developed in the private repository 8syncdev/kilop (access by invitation).

Machines with access install with a GitHub token (GH_TOKEN, GITHUB_TOKEN or gh auth login):

curl -fsSL https://get.8syncdev.com/install | sh       # Linux
irm https://get.8syncdev.com/install.ps1 | iex         # Windows
8sync up                                               # upgrade

Contact: 8syncdev.com
